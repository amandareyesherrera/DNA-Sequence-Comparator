# **Datos**

Esta carpeta contiene los archivos de secuencias de ADN utilizados en el proyecto DNA Sequence Comparator.

# **Objetivo**

El objetivo de esta carpeta es organizar los datos necesarios, es decir, las secuencias necesarias, para llevar a cabo los análisis y las comparaciones de secuencias de ADN. Para ello, se diferencian dos carpetas, una de secuencia de bacterias y otra de secuencia de virus, incluyendo ambas a su vez, otras dos carpetas, una que incluye las secuencias de referencia, las cuales sirven como modelo para realizar las comparaciones, y otra de las secuencias problema, cuyo contenido es el que se desea comparar y analizar.

# **Importancia de los datos**

Estos datos constituyen una parte fundamental del proyecto, ya que son la base sobre la que se realizan las comparaciones y análisis que nos permitirán conocer si existen cambios en las secuencias. Disponer de las secuencias de referencia nos permite establecer un punto sobre el que partir, de cara a la identificación de posibles diferencias, detección de mutaciones y cálculo del grado de similitud entre las secuencias analizadas.

Asimismo, mantener los datos organizados y separados según su finalidad va a permitir facilitar su identificación, lectura y procesamiento por parte de los distintos módulos del programa, contribuyendo a mejorar la organización del proyecto.

# **Contenido**

- **Carpeta secuencias 'Bacterias':** contiene la carpeta de secuencias de referencia y la carpeta de secuencias problema, de bacterias.
  - **Carpeta de secuencias de referencia:** almacena las secuencias bacterianas que se utilizan como modelo para realizar las comparaciones.
  - **Carpeta de secuencias problema:** almacena las secuencias bacterianas que se desean analizar y comparar con las de referencia.
- **Carpeta secuencias 'Virus':** contiene la carpeta de secuencias de referencia y la carpeta de secuencias problema, de virus.
  - **Carpeta de secuencias de referencia:** almacena las secuencias víricas que se utilizan como modelo para realizar las comparaciones.
  - **Carpeta de secuencias problema:** almacena las secuencias víricas que se desean analizar y comparar con las de referencia.
