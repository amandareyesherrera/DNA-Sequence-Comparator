# Tests

Esta carpeta contiene los archivos destinados a las pruebas del proyecto DNA Sequence Comparator.

## Objetivo

El objetivo de esta carpeta es organizar los casos de pruebas necesarios para verificar el correcto funcionamiento de los distintos módulos del proyecto, como la comparación de las diferentes secuencias de ADN, la identificación de posibles mutaciones, el cálculo de similitud entre ellas y la generación del informe. 

## Estructura

- **Carpeta test_sequences**: Contiene diferentes secuencias utilizadas como ejemplos para las pruebas.
- **test_sequence_reader.py**: Pruebas de lectura de secuencias.
- **test_mutation_detector.py**: Pruebas de detección de mutaciones.
- **test_similarity_calculator.py**: Pruebas de cálculo de similitud.
- **test_report_generator.py**: Pruebas de generación de informes.
- **test_main.py**: Pruebas del funcionamiento general del programa.
