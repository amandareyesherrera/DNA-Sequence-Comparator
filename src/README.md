# Documentación

Esta carpeta contiene los scripts empleados en el analisis compartivos de secuencias de DNA Sequence Comparator.

## Objetivo

El objetivo es realizar un analisas comparativo entre diferentes secuencias de DNA y la emision de informes. 

## Contenido

### mutation_detector.py

Contiene el script con los comandos empleados en el análisis

### report_generator.py

Contiene el script empleado para la generación de informes. 

### secuence_reader.py

Contiene el script empleado para la lectura de secuencias.

### similarity_calculator.py

Contiene el script empleado para realizar el cálculo de similitud así como la descripción de los criterios empleados.

### reports

contiene todos los informes emitidos y un documento en el que se recogen las secuencias fallidas

## Finalidad

Esta carpeta contiene los scripts empleados para llevar a cabo los aspectos analíticos del proyecto.
